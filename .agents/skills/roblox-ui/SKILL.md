# UI

`UIController` (`src/client/Controllers/UIController`) owns every screen. It ships with no screens; its `modules` table is empty. UI is Vide code. Nothing is authored in StarterGui.

```text
src/client/Controllers/UIController/
	init.luau       creates one ScreenGui per screen, fits it, opens and closes screens
	Scale.luau      fits Root to the ScreenGui
	Types.luau
	Kit/            hand-written helpers: Root, Image, Preview
	Looks/          generated, one per screen; never edit
	Screens/        hand-written, one per screen
	Stories/        optional UI Labs stories
src/shared/Config/UIAssets.luau   generated image ids and aspect ratios; never edit
```

## Look and Screen

- **Look** (`Looks/<Name>.luau`) is generated by the `/roblox-ui-maker` skill from approved HTML. It returns a Vide tree and takes an optional `Bindings` table. Never edit it: change the HTML and regenerate.
- **Screen** (`Screens/<Name>.luau`) is hand-written. It owns state and behaviour, and mounts the Look into the ScreenGui with `Vide.mount`.
- Bindings come from names in the HTML. `Text.<Name>` fills a label, `Activated.<Name>` handles a button, `Visible.<Name>` shows or hides an element. Pass a value, or a function that reads Vide sources.
- A renamed element changes the type of `Bindings`, so `./scripts/check.ps1` fails until the Screen is updated.

```lua
local ReplicatedStorage = game:GetService("ReplicatedStorage")
local Vide = require(ReplicatedStorage.Packages.Vide)
local Look = require(script.Parent.Parent.Looks.Shop)
local Types = require(script.Parent.Parent.Types)

local Shop = {}

function Shop.new(context: Types.Context, gui: ScreenGui): Types.Screen
	local cash = Vide.source(0)
	local unmount = Vide.mount(function()
		return Look({
			Text = {
				Cash = function()
					return string.format("%d", cash())
				end,
			},
			Activated = {
				Close = function()
					context.Close("Shop")
				end,
			},
		})
	end, gui)

	return {
		Modal = true,
		StartsOpen = false,
		Open = function(_self: Types.Screen)
			gui.Enabled = true
		end,
		Close = function(_self: Types.Screen)
			gui.Enabled = false
		end,
		Destroy = function(_self: Types.Screen)
			unmount()
		end,
	}
end

return Shop
```

## Adding a screen

1. Make the Look with the `/roblox-ui-maker` skill (see `ui/README.md`). It writes `Looks/<Name>.luau` and `UIAssets.luau`.
2. Add `Screens/<Name>.luau` from the template above.
3. Add `<Name> = require(script.Screens.<Name>)` to `modules` in `init.luau`. The key is the ScreenGui's name.
4. Run `./scripts/check.ps1` until clean.
5. Add a `Stories/<Name>.story.luau` if the user uses UI Labs. Wrap the Look in `Kit/Preview` so it scales to the preview frame.

## What `init.luau` does

- Waits for `PlayerGui`, then creates a ScreenGui named after the key: `ResetOnSpawn = false`, `ZIndexBehavior = Sibling`, and the default `IgnoreGuiInset = false`, so the screen sits below the top bar.
- Calls `Module.new(context, gui)`, sets `DisplayOrder` (modal screens 3, non-modal 2, so modals draw over the HUD), and refits whenever the ScreenGui's `AbsoluteSize` changes.
- Tracks which screens are open. Opening a modal closes other modals. Non-modal screens (HUD, notifications) can be open together.
- `Destroy` destroys every screen.
- API for other systems: `UIController:Open(name)`, `UIController:Close(name)` and `UIController:IsOpen(name)`.

## Scaling

- Every Look is a `Root` frame with a `FitScale` `UIScale` and `DesignW`, `DesignH`, and optionally `SafeW`, `SafeH` attributes. `Scale.luau` sets the scale and resizes `Root` to the ScreenGui. Screens never touch either.
- `scale = min(safeFit, max(stageFit, MinScale))`. `stageFit` fits the 1920x1080 design stage. `safeFit` fits the screen's safe box, so nothing important leaves the screen. `MinScale` (0.6) lifts small screens.
- `Root` fills the screen, so anything positioned from the top-left of the design stage can fall off a phone. Anchor elements to the edge or centre they belong to.
- A tap target should be at least 124 design pixels tall.

## Images

- Every image goes through `Kit/Image.luau`: `Image.Plain` and `Image.Button` take a width and compute the height from the asset's aspect ratio, so an image cannot be stretched. `Image.Slice` is the only way to stretch, and requires `SliceCenter` and `SliceScale`.
- Asset keys are `icon:<slug>` or `art:<key>`, resolved through `UIAssets`.
- `./scripts/check.ps1` fails on `create "ImageLabel"`, `create "ImageButton"` and `Instance.new` of either, outside `Kit/Image.luau`.

## Screen contract (`Types.luau`)

- A screen module returns `{ new = function(context, gui): Screen }`.
- The screen object has `Modal`, `StartsOpen`, `Open`, `Close` and `Destroy`.
- Screens may hold state. Clean up in `Destroy`: unmount the Vide root, disconnect connections and destroy a `Trove`.
- `context.Controllers` is the controller registry, and `context.Open` and `context.Close` open and close other screens. Screens never require each other.
- Screens may send requests through `Packets` and display player data through `context.Controllers.DataController` (see `.agents/skills/roblox-data/SKILL.md`). They never decide outcomes.
- Complex client logic such as a placement preview goes in its own controller, which the screen calls through `context.Controllers`.

## Vide notes

- `Vide.source(value)` holds state. Call it to read, and call it with a value to write.
- A property or `Text` given a function is reactive. Events take a plain function.
- `Vide.mount(fn, target)` builds inside a root and returns a function that destroys it.
- Strict mode (`Vide.strict = true`) catches duplicate property assignment; turn it on while developing if a Look misbehaves.
